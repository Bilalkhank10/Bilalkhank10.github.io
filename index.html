DATA WAREHOUSE · FEATURED

PSX Analytics — Pakistan Stock Exchange Data Warehouse

Fault-tolerant Python extractor pulls 24,600+ daily price records for 20 PSX large-caps plus USD/PKR and SBP policy rates into DuckDB. A dbt layer ships facts & dimensions — including a Type-2 slowly-changing dimension and ASOF currency joins — guarded by automated data-quality tests and freshness SLAs. A five-tab Streamlit dashboard serves the insights, refreshed daily by GitHub Actions.

📦 24.6k rows🧱 8 dbt models ✅ dbt tests🕰 SCD2 ⏱ daily CI

Stack: Python · yfinance · DuckDB · dbt Core · Streamlit · Plotly · GitHub Actions · Parquet
